INSTALL AKUMA IN A MICROVM  (read all of this once, then run the commands)

YOUR JOB: boot Akuma in a Firecracker microVM on THIS machine and run `busybox uname -a` inside it.
You are unattended. Run commands; do not describe plans; do not ask the user anything.

THE SCRIPT:  /home/netoneko/demo/scripts/install.sh   (POSIX sh)
THE FOLDER:  /home/netoneko/demo/run                  (everything the script makes goes here)
Use exactly these two flags on every call:  --vmm firecracker --dir /home/netoneko/demo/run

STEP 1  check the machine (fast):
    sh /home/netoneko/demo/scripts/install.sh check --vmm firecracker --dir /home/netoneko/demo/run
  Expect the last line:  install.sh: check: prerequisites present
  If it exits 10 a tool is missing: name the tool, say so, and STOP.

STEP 2  bring it up (takes 5 to 15 minutes: it downloads, builds a kernel and boots it).
  A command that long will time out if you run it in the foreground. Start it in the background:
    cd /home/netoneko/demo && nohup sh scripts/install.sh up --vmm firecracker --dir /home/netoneko/demo/run > up.log 2>&1 &
  Then wait and look, once a minute:
    sleep 60; tail -n 5 /home/netoneko/demo/up.log
  Repeat until the log contains the line  AKUMA_READY=1  (success) or a line starting  install.sh: FAIL  (failure).
  Do not start `up` twice while it is running.

STEP 3  run a command inside the VM:
    sh /home/netoneko/demo/scripts/install.sh ssh --dir /home/netoneko/demo/run 'busybox uname -a'
  Success looks like:  Linux taoxichuan 0.1.0-... x86_64 GNU/Linux

YOU ARE DONE when step 3 printed a line starting with  Linux taoxichuan . Say DONE and paste that line.
Leave the VM running. Do not run `down`.

IF A STEP FAILS
  - Every failure prints a line  install.sh: FAIL stage=<name> <reason>  and the last 20 lines of that stage's log
    (/home/netoneko/demo/run/logs/<name>.log). Read them.
  - Run `up` once more the same way: it resumes where it stopped. If it fails a second time, STOP and report the
    FAIL line and the exit code.

RULES
  - No sudo. No apt, pip or any package install. Do not delete anything outside /home/netoneko/demo/run.
  - Do not kill processes you did not start. Do not touch other folders.
  - Never claim success without having seen the Linux taoxichuan line yourself.
