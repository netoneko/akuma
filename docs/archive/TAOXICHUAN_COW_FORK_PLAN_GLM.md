## 1. What the repo already has

**The decision, already extracted** — `crates/akuma-cow` (read in full; see also `docs/archive/AKUMA_AMD64_COW.md`): `CowFault { pte_writable, marked, refs }` → `decide()` → `CowAction { Retry, Fault, TakeInPlace, Copy }`, `resolves()`, `needs_frame()` (only `Copy` can OOM). Test order is the substance: `pte_writable` first (a live-writable PTE ⇒ `Retry`, the `cowstale` answer — **re-read the PTE in the handler, don't trust the error code**), `marked` before `refs` (the PTE bit, not the count — an `mprotect(READ)` page with a coincidentally shared frame must not be promoted; `docs/archive/GRANT_RECORDS_VS_DENY_RECORDS.md`), `refs <= 1` ⇒ `TakeInPlace` (0 = PMM "untracked single owner"; the fork-then-exec common case), else `Copy`. AArch64's `marked: refs > 0` adapter is a pinned divergence — x86_64 has the bit, so Taoxichuan gets the real decision.

**The global refcount + proof instruments** — `crates/akuma-pmm` (bodies read): see premise 5. Contracts the share loop/fault arm must honor: inc once per frame (inserts 2); `Copy` ⇒ `cow_ref_dec(old)` (2→1, never frees at refs>1); `TakeInPlace` ⇒ clear the marker only, **leave the entry at 1** (the final `free_page` later drops 1→0 and frees); untracked frames free unconditionally — so a private frame needs no count at all.

**The per-address-space ledger** — `crates/akuma-user-space` `FrameLedger`: `track_user_frame`, `adopt_user_frame(frame, caller_holds_ref)` (updates the **global** CoW count in the same uninterruptible window as the per-space count — written for exactly the fork-share moment), `remove_user_frame`, page-table tracking, `resident_pages()`.

**The owner crate** — `crates/akuma-exec`: `Process` + `ProcAddressSpace` (owned or `new_shared` view), `fork_process` (step 1 fresh child space, step 2 the hook, step 3 publish runnable), `reclaim::drain_retired`, `hold_exited_thread_slot`, `unregister_process`, `runtime.rs:258` the `fork_share_memory: fn(&Process, &mut Process) -> Result<(), &'static str>` hook.

**The machine crate** — `crates/akuma-mmu`: `UserAddressSpace` (`new_shared`, `l0_phys`), `Prot`/`to_pte`/`from_prot` (types.rs — no bit-9 vocabulary today; the natural home for a `cow` bit if extracted amd64-style, question 4), `TlbFlush`/`TlbTarget`, `drain_pending_ttbr_frees` (every reap calls it today).

**Taoxichuan's own pieces** (all read): the eager cloners (`fork_share_memory`, `clone_user_half`, `clone_user_tree` — walk PML4 0..256 only, refuse PS leaves, copy parent flag bits verbatim); `fault_trap` + `grow_user_stack` (the resumable fault skeleton — stack growth must stay the **first** arm); `free_user_root` (L4886: full root walk, `free_page` per leaf **and** per table frame, refuses the live CR3); `park_root`/`sweep_parked_roots`/`adopt_exec_root`/`OWNED_ROOT` (deferred root frees at reap/exec); `disown_space` (crate owned space → `new_shared` view, `forget` the owned one — the ledger-blindness compromise, heap-only residue); `release_pages` (L997: `unmap_page_in` + `free_page` — **munmap is already CoW-correct**, and it is real, gated only by `mmdbg()` bit 1, default 7: memory.md's "accepted no-op" claim is stale); `mprotect_arm` (L904: re-maps present pages — must learn the bit-9 decode/preserve rule); `mmap` + `t.shared` (writable `MAP_SHARED` file mappings are per-process copies with writeback `shared_writeback`/`shared_flush_all` at munmap/exit); the `[reap]`/`[spawn-reap]` per-reap `free_count()` before→after prints (child.rs 2071–2135, `trace-err`); per-slot x87/SSE save (`exec_twin.rs` FX[slot], `fxsave64`/`fxrstor64`, L158–198).

**The reference implementation** — `amd64/src/` as documented (`AKUMA_AMD64_COW.md`, `docs/reference/subsystems/memory.md` § "CoW fork" L332–390): share pass (`cow_share_range`: per page `cow_ref_inc` + **both** sides demoted RO + `track_user_frame`), demote under the owner's address-space lock, `AllCores` shootdown after the walk and before the `Copy` arm's free, fault arm after demand paging / before the user-copy fixup, teardown through `cow_ref_dec` at every release site, thread-group-leader locking for `cowstale`.

**What must be extracted from `amd64/src/` first: nothing large.** Decision (`akuma-cow`), refcount (`akuma-pmm`), ledger (`akuma-user-space`) are already crates. What gets **ported as patterns**, not code (amd64's is welded to its region table, which Taoxichuan doesn't have): (1) demote-both-sides + skip-unmarked-RO; (2) fault-arm ordering (stack growth first); (3) release-through-`cow_ref_dec` — Taoxichuan **already has this everywhere that matters** (`free_page` in `free_user_root`, `release_pages`); (4) the marker bit decode rule (amd64's grandchild-fork bug: drop the decode and the second fork un-marks every page). Optional, question 4: `Prot::cow()` + decode in `akuma-mmu`, host-tested like amd64's.

## 2. The page-fault path in Taoxichuan

Today: `static IDT: idt_lib::Idt` (`akuma-idt-amd64` table + `akuma-trap-amd64` stubs) in main.rs; **`fault_trap` is the one handler**. For #PF: reads error code, reads CR2 via `akuma_cpu::ctlreg::cr2()`; `from_ring3() && code & 1 == 0` (not-present) → `grow_user_stack` may **return and retry**; otherwise prints `[Fault] ring3 … -- task killed` and ends the task alone (`task_die_segv`, wait status 11/`rc=139`) or, for kernel-origin faults, prints and halts. **The IDT work for CoW is zero** — only `fault_trap` grows a second arm.

The CoW arm, concretely:

1. **Order**: `grow_user_stack` first (not-present ≠ CoW; amd64's "fault arm after demand paging" maps here). Then: `from_ring3() && (code & 1) (present) && (code & 2) (write) && (code & 4) (user)`.
2. **The task's own root**: `task().root_pa` / `sched_root_of(current_slot())` — never a blind CR3 read (kernel faults must keep halting).
3. **Re-read the PTE** at CR2 by walking the 4-level user tables through the physmap (the walk `free_user_root` demonstrates; single level-0..256 half). **Never trust the error code's RW judgment — `akuma-cow`'s `CowFault::pte_writable` doc is explicit**: read the live PTE inside the handler; a stale read turns a repaired page into a kill (the `cowstale` class).
4. **Decide** with `akuma_cow::decide` (`pte_writable = PTE & 2`, `marked = PTE & (1<<9)` AVL, `refs = cow_ref_get(frame)`):
   - `Retry` ⇒ plain return (instruction re-executes on a repaired page; count it).
   - `Fault` ⇒ fall through to today's kill path (correct for text, `.rodata`, `mprotect(READ)`).
   - `TakeInPlace` ⇒ remap same frame USER_RW, clear bit 9, `invlpg`, return. **No refcount change** (entry stays at 1; the eventual `free_page` removes it).
   - `Copy` ⇒ `alloc_page_zeroed` → copy 4 KiB through the physmap → `map_page_in(root, page, new, USER_RW, WriteBack)` → `cow_ref_dec(old)` (2→1; frees only if this was somehow last) → `invlpg` → return. OOM (`needs_frame`) ⇒ today's kill path with the frame address in the report.
5. **TLB invalidation on the right CPU**: single core (all tasks multiplexed on one; preemption is a same-core tick) ⇒ core-local `invlpg` (`akuma-cpu`) after **every** PTE write is sufficient — no IPI, no `TlbTarget::AllCores` machinery (that exists on amd64 because it is SMP>1). But the **fork share loop** must `invlpg` every parent leaf it demotes: the parent resumes with hot W translations, and a stale W entry writes straight into the shared frame — silent divergence, no fault, worse than a leak. The loop runs in the fork syscall with the parent parked and IF clear: race-free.
6. **The `copy_to_user` interaction (premise 4)**: kernel physmap writes never fault, so the handler cannot serve them. A resolve helper — `cow_resolve_for_kernel_write(root, va)`: translate; leaf RO+marked+`refs>0` ⇒ run the same `decide()` path synchronously (Copy/TakeInPlace, `invlpg`), then let `copy_to_user` write. `copy_from_user` and other reads need nothing. amd64's alternative (user-copy fixup through the fault arm) has no analog here — there is no fixup path; the helper is the local equivalent, and the S4 grep-audit of `translate_in` + physmap-write sites is the completeness check.

## 3. Frame ownership and refcounts

**Who holds the count**: a frame shared by parent and child has `cow_ref_get == 2` (the inc inserts 2 — one call per frame, not per side); each holder's PTE names the frame RO with bit 9 set. A private frame (fresh alloc, ELF load, stack growth) has **no entry** — `cow_ref_get == 0` legitimately means "single owner, free it" (`subsystems/memory.md` § invariants). `cow_ref_inc` belongs **only** where a second holder appears — here, the fork share loop, and nothing else (no shared file-page cache exists in Taoxichuan).

**How drops work — audited, every path already reaches `free_page` (⇒ `cow_ref_dec`, free-on-last):**

- **exec** (`load_task` in place; `exec_replace`/`exec_real_task`): fresh root; old root parked → `sweep_parked_roots` → `free_user_root` → `free_page` per frame. Already CoW-correct: the child that execs over its fork clone drops every parent frame 2→1 and frees only its own cloned tables — the `TakeInPlace` payoff (fork+exec copies ~nothing).
- **exit/reap** (`task_exit_status` → zombie hold (`hold_exited_thread_slot`) → parent `wait4` → `reap_process`): `OWNED_ROOT` or the task-record root → `disown_space` + `park_root` + sweep → `free_user_root`; plus `unregister_process` → `drain_retired` → crate-side `UserAddressSpace::drop`. Page-table frames are never shared (tables are cloned per root; only leaves share) ⇒ unconditional table frees stay correct.
- **munmap** (`munmap_arm` → `release_pages`): `unmap_page_in` + `free_page` — **verified CoW-correct** (and real by default: `mmdbg()` bit 1, default 7; memory.md's "accepted no-op" is stale). Needs no change; its writeback read path (`shared_writeback`) reads, so demotion is invisible to it.
- **mprotect** (`mprotect_arm`): re-maps present pages. Must (a) preserve bit 9 when stripping/granting W, (b) on W-upgrade of a marked page, break CoW first (resolve, then remap). Missing the decode is exactly amd64's grandchild-fork bug.
- **The ledger-blindness fix** (2026-10-30 finding: the twin's raw copied frames were invisible to the crate ledger; `disown_space` `forget`s the owned space; the twin frees the whole root by hand — a forked 100k-page rustc left 104k pages per fork): with CoW the flood disappears by construction — the twin shares instead of copying, and `free_user_root` drops counts instead of blindly freeing. Remaining coupling: the twin should `adopt_user_frame(frame, caller_holds_ref = true)` per shared leaf inside the share loop's single IF-clear window (that is `adopt_user_frame`'s documented purpose — global count + ledger in one hold), so a crate-side drop can never double-free. Honest fallback, if that proves noisy: keep the crate ledger a `new_shared` view (what `disown_space` installs anyway), let the twin's `free_user_root` be the sole framer, and write that decision down in the twin per the `AKUMA_AMD64_STALE_FALSE_HOOKS.md` honesty rule. The log's known heap-only residue ("a few hundred bytes per fork-exec", log L1628) is untouched and excluded from the frame gate.
- **Slot recycling** (`hold_exited_thread_slot`, TERMINATED→FREE, `x86_claim_slot`): orthogonal; no change (and note amd64's `Finished`-state fork ceiling lesson is already structurally answered here by the zombie hold).

**`MAP_SHARED` writable file pages must NOT be CoW'd** (brief; `akuma-fpcache-rw` history: amd64 needed `AKUMA_AMD64_SHARED_WRITABLE_PAGES.md`'s shared-writable table because per-process copies diverged — SQLite WAL). Taoxichuan keeps per-process copies + writeback (`t.shared` spans in the task record, `shared_writeback`/`shared_flush_all`). The share loop skips any leaf inside a `t.shared` span (eager copy exactly as today — no writeback-semantics change). amd64's `fpcache-rw` end-state is out of scope.

## 5. The leak proof

**Instrument** (exists): `akuma_pmm::free_count()`; per-reap prints already in place (`[reap] pid=… free N -> M`, `[spawn-reap] …`, child.rs, `trace-err`). Add: boot-idle baseline line `[leak-gate] baseline free=N` (after init, before any spawn) and a summary `[leak-gate] base=N end=M bound=B PASS|FAIL` after the battery (feature: `trace-err`, or a dedicated `leakgate` — question 3).

**Cycles** (N = 20 each, driven from the sshd session the runner owns):
1. **fork+exec+exit** (`busybox true` / `sh -c 'exit 0'`) — the TakeInPlace-heavy common case.
2. **fork+write-to-shared-page+exit**: `sh -c 'x=parent; (x=child; echo in-sub=$x); echo after=$x'` — forces Copy breaks both directions; the exact AKUMA_AMD64_COW.md probe.
3. **fork+exit-without-touching** (a forked static hello that exits) — pure share-then-teardown; catches double-drops with no breaking noise.

**Bound and why**: after all cycles + one final wait4 drain + `sweep_parked_roots`/`drain_retired`, require `M ∈ [N−4, N+4]` and the per-cycle `[reap]` deltas summing to 0. The ±4 is *stated* slack for drain ordering (parked-root frees and quarantine/`drain_pending_ttbr_frees` can lag one cycle), **not** for leaks — a correct implementation returns exactly to baseline; if the bound is ever load-bearing (M=N−4 repeatedly), the gate must fail. (Exact-0 variant: question 2.)

**Share vs leak, distinguishable** — the raw count alone cannot tell them apart, so the gate adds two checks: (a) `cow_ref_count()` must be **0 at idle** (every cycle's parent and child exited; a surviving entry names its holder via `print_cow_history(pa)`); (b) any frame with `is_page_free == false`, `cow_ref_get == 0`, and no live mapper is a leak by definition — the quarantine's `[PMM-RESURRECT]` lines (printed on a 0→0 inc/dec path, capped at 32 prints) are the tripwire, and any in the gate window fails the run. Per-frame diagnosis: `akuma_pmm::print_cow_history(pa)` + `last_free_record_at`'s `FreeSite` (names the releasing code path) + `leak_count()`.

**Where**: a new row in `run_gates.sh` asserting the `[leak-gate] … PASS` line (silent probe ⇒ fail, gates.md rule). Battery order keeps the already-green gates green by construction.

## 6. Risks and unknowns (each with the cheapest resolution)

1. **Stale parent TLB after demotion** — silent cross-process writes, no fault. Cheapest: `invlpg` per demoted parent leaf inside the share loop (parent parked, IF clear ⇒ race-free single-core); S3's isolation one-liner exercises it.
2. **Kernel physmap writers bypass faults** (premise 4): `copy_to_user` targets, `shared_writeback` (reads only — safe), pipe fills. Cheapest: the S4 grep-audit of `translate_in` call sites; resolve-before-write only where a page can be marked-and-shared.
3. **`MAP_SHARED` writable pages** must skip CoW (writeback divergence; `akuma-fpcache-rw` end-state out of scope). Cheapest: share loop consults `t.shared` spans; an apk/git run exercises mmap-writes in S2's gate.
4. **Huge (PS) leaves**: refused today (`None` ⇒ fork fails). Loader maps 4 KiB only ⇒ should never fire; keep refusal, add the leaf address to the report (AKUMA_AMD64_COW.md's "ENOMEM naming the wrong resource" lesson).
5. **vfork-style `clone(CLONE_VM|CLONE_VFORK)`**: shares the parent's root; the share loop must never run for a thread-shaped child. Cheapest: dispatch on `ChildKind` in the twin hook + P-gates + `git clone` as regression; user's ladder (keep working, else honest not-implemented) governs (question 5).
6. **Multi-thread processes sharing one root** (`group_leader`/`kill_siblings` exist): demote once per root, only in `fork_process`'s arm; the fork syscall's IF-clear window is the "owner's address-space lock". Thread children are `clone_thread` — same task record, same root, nothing to share.
7. **The `cowstale` fault class** (`COWSTALE_FORK_THREAD_SEGV.md`; `AMD64_FORK_VS_THREADS_SEGV.md` — the famous "CoW bug" that was actually a signal-return bug: the archive's own warning against blaming CoW first): implement `Retry` from the live-PTE re-read regardless of single-core reasoning (the crate exists to pin this order); count retries.
8. **x87/SSE state** — fixed 2026-10-30 (log L1641; per-slot 512-byte `FX` areas, power-on `FCW 0x37F`/`MXCSR 0x1F80`, reset on slot reuse; `exec_twin.rs:158–198`): no CoW interaction; the cargo `-j4` triple gate guards against regression noise.
9. **Stack-guard and TLS pages**: stack growth stays the first fault arm; fs discipline at exec (zeroed) untouched (ph-7's PK2 lesson documented in child.rs). Cheapest: PK1 per slice.
10. **Teardown regression** (the 2026-10-30 fixes): page tables at reap — S2 keeps table frames per-root, unconditional frees (`free_user_root` counts them); ledger blindness — replaced by counts (§3); slot recycling — untouched. Cheapest: S5's per-cycle deltas.
